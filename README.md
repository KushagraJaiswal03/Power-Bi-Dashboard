# Power-Bi-Dashboard
# Data Professional Survey Breakdown | Power BI Dashboard

An interactive Power BI dashboard analyzing survey responses from **630 data professionals** worldwide — exploring roles, salaries, tools, and job satisfaction across the data industry.

<img width="1917" height="960" alt="image" src="https://github.com/user-attachments/assets/b5c0c198-1986-4beb-bf09-bc2200bc57ab" />

## 📌 Project Overview

This project turns raw survey data into a clear, interactive story about who works in data, what tools they use, and how satisfied they are in their roles. It was built to practice data cleaning, DAX measures, and dashboard storytelling in Power BI.

**Questions this dashboard answers:**
- What roles do data professionals hold, and how are they distributed?
- Which programming languages are most popular, and does that vary by role?
- How does average salary differ by job title?
- Where in the world do respondents live?
- How satisfied are people with salary and work/life balance?
- How difficult is it to break into a data career?

## 📊 Key Insights

| Metric | Finding |
|---|---|
| Total respondents | 630 |
| Most common role | Data Analyst (60%) |
| Favorite language | Python (67%), ahead of R and SQL |
| Top countries | United States, India, United Kingdom |
| Average age | ~30 years old |
| Breaking into data | 30%+ rated it "Difficult" or "Very Difficult" |

## 🖥️ Dashboard Features

- **Column chart** — role distribution by favorite programming language
- **Clustered bar chart** — average salary by job title
- **Treemap** — respondent breakdown by country
- **Donut chart** — difficulty of breaking into the data field
- **Gauges** — satisfaction scores for salary and work/life balance
- **KPI cards** — total respondents and average age

## 🛠️ Tools & Skills Used

- **Power BI Desktop** — data modeling, DAX measures, dashboard design
- **Power Query** — data cleaning and transformation
- **Excel** — initial data inspection

- Cleaning messy, open-ended survey responses ("Other: please specify" fields)
